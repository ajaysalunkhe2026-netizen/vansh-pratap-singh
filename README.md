# Vansh Pratap Singh — Professional Portfolio

A professional portfolio website for a Medical / Pharmaceutical Sales Officer.

## About
This site is designed to present professional experience, product knowledge, sales capabilities, achievements, and business contact information.

## Important content note
Personal details, employer names, qualifications, territories, product claims, achievements, and contact information are intentionally left as editable placeholders until verified by Vansh. No medical advice or unverified product claims are published.

## Website
Open `index.html` locally, or enable GitHub Pages from **Settings → Pages** and deploy from the `main` branch (root).

## Customize
Edit the `PROFILE` section in `index.html` to add verified details. Replace placeholder contact links before publishing.
